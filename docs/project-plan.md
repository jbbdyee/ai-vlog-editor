# AI Vlog Editor - Project Plan

## 1. 프로젝트 한 줄 정의

사용자가 촬영 중 남긴 자연어 편집 의도와 이후 수정 요청을 바탕으로,
긴 원본 영상의 탐색부터 실제 편집까지 수행하는 개인화 AI 브이로그 편집 서비스.

---

## 2. 문제 정의

브이로그 촬영 자체보다 촬영 이후의 편집 과정에 많은 시간과 노력이 필요하다.

특히 몇 시간 분량의 원본에서 사용할 장면을 다시 찾고,
불필요한 부분을 제거하고, 자막을 작성하고,
사용자의 취향에 맞게 편집하는 과정이 반복적인 부담이 된다.

완전 자동 편집은 시간을 줄일 수 있지만,
AI가 사용자가 생각하는 재미있는 장면이나 중요한 순간까지
정확하게 판단하기 어렵다는 문제가 있다.

따라서 이 프로젝트는

> 사용자의 창작 판단은 남기고,
> 반복적인 탐색과 편집 노동은 AI에게 맡긴다.

를 핵심 원칙으로 한다.

---

## 3. 핵심 사용자 흐름

1. 사용자가 영상을 촬영한다.
2. 촬영 중 필요한 순간에 자연어 편집 메모를 남긴다.
   - "AI야 방금 장면 꼭 살려줘."
   - "여기는 짧게 써줘."
3. 촬영한 원본 영상을 업로드한다.
4. AI가 음성을 STT로 변환하고 편집 지시를 탐지한다.
5. 편집 지시와 관련된 장면 후보를 찾는다.
6. 사용자가 후보 장면을 빠르게 확인한다.
7. AI가 편집 계획을 생성한다.
8. 실제 영상 초안을 생성한다.
9. 사용자는 자연어로 수정 요청을 한다.
10. AI가 수정 의도를 해석하고 실제 영상에 다시 반영한다.

---

## 4. MVP v1

첫 번째 목표는 전체 서비스를 완성하는 것이 아니다.

다음 흐름 하나를 실제로 동작시키는 것을 목표로 한다.

### Input

짧은 테스트 영상 업로드

### Process

영상
→ 오디오 추출
→ STT
→ 타임스탬프 생성
→ 촬영 중 편집 메모 탐지
→ 메모 주변 장면 구간 결정
→ FFmpeg 영상 자르기

### Output

사용자가 촬영 중

"AI야 방금 장면 꼭 살려줘."

라고 말한 장면을 찾아 실제 MP4 클립으로 출력한다.

### MVP v1 성공 기준

테스트 영상에서 편집 메모를 탐지하고,
관련된 장면을 실제 영상 파일로 추출할 수 있다.

## 7. 기술적으로 도전할 문제

### 1. 자연어 편집 지시 탐지

일반적인 대화와

"AI야 방금 거 살려줘."

같은 편집 지시를 구분해야 한다.

### 2. "방금"이 가리키는 장면 찾기

편집 지시가 발생한 시간만 기준으로 자르는 것이 아니라,
주변 대화와 장면 정보를 이용해 실제 필요한 구간을 찾아야 한다.

### 3. 자연어를 실제 편집 명령으로 변환

예:

"카페 부분은 줄이고 야경은 길게 해줘."

라는 요청을 실제 영상 구간과 편집 작업으로 변환해야 한다.

### 4. LLM과 영상 처리 도구 연결

LLM이 텍스트만 생성하는 것이 아니라,
판단 결과가 FFmpeg 등의 실제 도구 실행으로 이어져야 한다.

### 5. 사용자 편집 취향 학습

반복적인 수정 기록에서 편집 취향을 추출하고
다음 영상에 반영할 수 있어야 한다.

## 8. 프로젝트 원칙

기능을 추가하기 전에 다음을 확인한다.

1. 긴 영상의 편집 노동을 실제로 줄이는가?
2. 사용자의 편집 의도를 보존하는가?
3. AI가 필요한 이유가 명확한가?
4. 실제 영상 결과물에 영향을 주는가?
5. 구현 결과를 측정하거나 검증할 수 있는가?

위 조건과 관계없는 기능은 우선순위를 낮춘다.
