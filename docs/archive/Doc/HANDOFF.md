  - `rawBody`로 원본 바이트를 받을 수 있다.
  - JSON을 다시 직렬화하면 바이트가 달라진다(`12.0`→`12`).
  - 실행 이력에는 서명만 남고 키는 0회다.

  - 허용 오차는 실제로 300초 ± 1초(정수 초 경계)다.
