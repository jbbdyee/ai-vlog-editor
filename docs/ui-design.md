## 설계 목표

사용자가 직접 긴 영상을 다시 보면서 편집하지 않고,
중요한 장면과 편집 의도만 최소한으로 전달할 수 있도록 설계한다.

## 핵심 UX 원칙

- AI가 모든 편집 판단을 임의로 대신하지 않는다.
- 사용자는 중요한 장면과 의도만 전달한다.
- AI는 장면 탐색, 컷 편집, 자막 생성 등 반복 작업을 수행한다.
- 긴 원본을 다시 보는 시간을 최소화한다.

## v0.2 - Scene Memo UX 변경

### 문제 발견
초기에는 사용자가 업로드한 영상을 다시 확인하면서
중요한 장면을 직접 표시하는 방식을 고려했다.

하지만 몇 시간 분량의 원본을 다시 확인해야 한다면,
기존 영상 편집에서 발생하는 탐색 노동을 충분히 줄이지 못한다고 판단했다.

### 변경 방향
촬영 중 사용자가 자연어로 편집 메모를 남기는 방식을 핵심 입력 방식으로 변경했다.

예:
- "AI야 방금 장면 꼭 살려줘."
- "이 부분은 짧게 써줘."
- "여기부터는 빼도 돼."

업로드 후 STT와 타임스탬프를 이용해 편집 지시를 탐지하고,
지시가 발생한 시점 주변에서 관련 장면을 자동으로 탐색한다.

촬영 중 메모하지 못한 장면은
업로드 후 자연어 검색으로 추가할 수 있도록 설계한다.

### 변경 이유
AI가 모든 하이라이트를 임의로 결정하면
사용자가 생각하는 재미와 중요도를 놓칠 수 있다.

반대로 사용자가 전체 영상을 다시 확인하면
편집 시간을 줄인다는 서비스 목적이 약해진다.

따라서 사용자의 판단은 유지하면서
장면 탐색 노동을 최소화하기 위해
'촬영 중 자연어 메모 + 촬영 후 AI 장면 탐색' 방식을 선택했다.

### 추가된 화면
- Scene Memo

### 결과

- 촬영 중 자연어 메모를 기준으로 장면 후보를 보여주는 Scene Memo 화면을 설계했다.
- 사용자는 전체 영상을 다시 탐색하지 않고 AI가 찾은 후보 장면만 빠르게 확인할 수 있도록 구성했다.

## v0.3 - AI Edit Result 화면 설계

### 설계 목표

AI 편집 결과만 보여주는 것이 아니라,
사용자가 AI가 수행한 작업과 편집 결과를 한눈에 확인할 수 있도록 설계했다.

### 주요 정보

- 원본 영상 길이
- AI 편집 후 영상 길이
- 영상 분량 감소율
- 편집된 영상 미리보기
- AI가 적용한 편집 작업
- 수정 요청 / 편집 완료

### 설계 판단

AI가 생성한 결과만 제공하면 사용자는
어떤 작업이 적용되었는지 확인하기 어렵다.

따라서 결과 영상과 함께
AI가 수행한 편집 작업을 요약해서 제공하도록 설계했다.

### 결과

사용자는 편집 결과를 확인한 뒤
결과를 확정하거나 자연어 수정 요청 단계로 이동할 수 있다.

## v0.4 - Natural Language Edit Request 화면 설계

### 설계 목표

사용자가 복잡한 영상 편집 도구를 직접 조작하지 않고,
자연어로 원하는 수정 내용을 전달할 수 있도록 설계했다.

### 주요 기능

- 현재 편집 영상 미리보기
- 자연어 수정 요청
- AI의 수정 의도 해석
- 적용 예정인 편집 작업 확인
- 수정된 영상 재생성

### 설계 판단

자연어 요청을 받은 즉시 영상을 수정하는 방식보다,
AI가 이해한 편집 내용을 먼저 사용자에게 보여주도록 설계했다.

예:

"카페 부분은 조금 줄이고 마지막 야경은 더 길게 살려줘."

↓

- 카페 장면 축소
- 야경 장면 길이 증가

↓

사용자 확인 후 편집 적용

이를 통해 AI가 사용자의 의도를 잘못 해석했을 때
원하지 않는 편집이 바로 적용되는 문제를 줄이고자 했다.

### 향후 확장

사용자의 반복적인 수정 요청을 저장하고 분석하여
개인별 편집 취향을 학습하는 Editing Profile로 확장할 예정이다.
