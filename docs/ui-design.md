## 설계 목표
사용자가 직접 영상 편집을 하지 않고,
중요한 장면과 편집 의도만 최소한으로 전달할 수 있도록 설계한다.

## v0.1 화면
- Home
- Video Upload
- Scene Memo
- AI Edit Result
- Edit Request

## 핵심 UX 원칙

AI가 임의로 모든 편집 판단을 대신하지 않는다.

사용자는 중요한 장면과 편집 의도만 최소한으로 전달하고,
AI는 장면 탐색, 컷 편집, 자막 생성 등 반복적인 편집 작업을 수행한다.

## 현재 설계 판단
초기 MVP는 모바일보다 웹 화면을 우선한다.

이유:
긴 영상, 장면 후보, 편집 결과를 한 화면에서 확인해야 하므로
데스크톱 환경이 초기 구현과 테스트에 더 적합하다고 판단했다.
