# 촬영 체크리스트 — G5-B2

촬영 전 [시나리오 manifest](recording-scenarios.json)를 읽으세요. P1 전체 → P1 주석·고정 → P2 전체 → P2 주석·고정 → P3 전체 → P3 주석·고정 순서로 진행할 수 있습니다. **세 Project가 모두 고정되기 전에는 semantic Provider를 실행하지 않습니다.** 실제 시간 정답은 촬영 후 원본을 보며 G5-B4에서 기록합니다.

각 Source마다 확인:

- [ ] `P1-S01` 같은 Scenario ID와 행동·말·메모 문장을 확인했다.
- [ ] 얼굴, 주소, 건물·차량 번호, 이름표, 문서, 모니터 알림이 보이지 않는다.
- [ ] 손·사물·공간 중심으로 찍고, 외부 VLM에 보낼 장면에는 얼굴이 없다.
- [ ] 필요한 방해 행동과 침묵/발화가 자연스럽게 포함됐다. 억지 filler는 넣지 않았다.
- [ ] 20–45초는 권장 범위이며 의미 조건을 위해 약간 달라도 된다.
- [ ] 촬영 후 실제 파일명을 로컬 기록에 남겼다. Git에는 영상을 올리지 않았다.
- [ ] 아직 AI/semantic Provider 결과를 보지 않았다.

권장 로컬 파일명은 `P1_S01_take01.mov`처럼 중립적 ID만 사용합니다. `same_event.mp4`, `no_match.mp4`, `ambiguous.mp4`처럼 답을 드러내지 마세요. 재촬영은 `take02`로 로컬 보관할 수 있으나, **GT 고정 전·모델 실행 전** 최종 평가 take를 고릅니다. 촬영 실수, 개인정보 노출, 행동 누락, 의도한 모호성 실패는 모델 실행 전에 재촬영할 수 있습니다. 모델 결과를 본 뒤 시나리오 의도를 바꾸지 마세요.
