P0 변경의 근거는 [HANDOFF](HANDOFF.md)와 [실사 데모 기록](../docs/handoff/demo-01-portfolio-edit-flow.md)에 둔다. 2초 합성 영상의 신규 Docker 하드 자막 생성·한글 프레임은 확인했고 새 실사 영상 전체 렌더 품질은 미검증이다. 구현 완료와 실행 서버 반영, 테스트 통과와 실제 사용자 흐름 확인은 각각 별도로 판정한다. 새 기능, 대규모 리팩터링, Redis 작업 큐 도입, 공개 배포는 제출 범위 밖이다.

2026-11-04 사전 점검 당시에는 기존 `start_server.py`에 비밀 값이 아닌 Ollama 편집·VLM 모델과 로컬 URL을 명시하는 선택 인자를 추가하고, 격리 DB(55432)·미디어의 8014에서 설정을 검증했다. **이후 승인받아 기존 8000을 PID 13384의 최신 코드로 교체했다.** 현재 실행 결과와 한계는 [HANDOFF](HANDOFF.md)를 따른다.
